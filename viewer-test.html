走進風景

點任何一張照片，照片會從卡片放大成全螢幕的偽 3D 場景。移動滑鼠（手機請傾斜）感受景深，← → 切換景點，Esc 關閉。

改用 CSS 後備 —
  1. FLIP：從卡片圖片無縫放大 / 關閉時縮回同一張卡片（切換到別的景點後關閉 → 卡片不在畫面中則淡出）。
  2. 深度視差跟著滑鼠；閒置 ~3 秒後鏡頭自動緩慢漂移；開啟時有一次景深推進。
  3. FX 特效疊在照片上（瀑布 / 間歇泉 / 冰河 / 極光 / 冰洞）。
  4. 開啟時頁面不能捲動；關閉後焦點回到原本的卡片圖片。
  5. ?nogl 會改用 CSS 視差後備模式；file:// 開啟時也會自動退回。
